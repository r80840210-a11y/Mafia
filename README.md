# 🎭 MAFIA ONLINE

Полнофункциональная браузерная мультиплеерная игра "Мафия" для 4–10 игроков.

## 🚀 Особенности

- **Онлайн-мультиплеер** через WebSocket (Socket.IO)
- **Локальный режим** для игры на одном устройстве
- **Система аккаунтов** с регистрацией и авторизацией (PostgreSQL)
- **Авторитетный сервер** — все решения принимаются на серверной стороне
- **11+ ролей**: Мирный, Комиссар, Доктор, Маньяк, Шут, Дон, Мафия, Адвокат, Ведьма, Шериф, Телохранитель, Следователь
- **Полная логика игры**: ночные действия, дневное обсуждение, голосование, определение победы
- **Профили, рейтинг, достижения, статистика**
- **Адаптивный дизайн** для мобильных и десктопных устройств

## 📦 Установка и запуск локально

### Шаг 1: Клонировать / Распаковать проект

```bash
# Если скачали ZIP:
unzip mafia-game.zip
cd mafia-game
```

### Шаг 2: Установить зависимости

```bash
npm install
```

### Шаг 3: Настроить БД

Для разработки используется SQLite (встроенная). Для продакшена нужен PostgreSQL.

**Для локальной разработки (SQLite):**

Отредактируйте `server/db.js` и замените подключение на SQLite:

```javascript
const db = require('better-sqlite3')('./mafia.db');
```

И установите:
```bash
npm install better-sqlite3
```

**Для продакшена (PostgreSQL):**

1. Создайте БД:
```bash
createdb mafia
psql mafia < server/schema.sql
```

2. Экспортируйте переменную окружения:
```bash
export DATABASE_URL="postgresql://user:password@localhost:5432/mafia"
```

### Шаг 4: Запустить сервер

```bash
npm start
```

Сервер запустится на `http://localhost:3000`

Откройте два окна браузера:
- Окно 1: http://localhost:3000 → регистрируйтесь как Player 1
- Окно 2: http://localhost:3000 → регистрируйтесь как Player 2

Создайте комнату, пригласите друга по коду, и начните играть!

## 🌐 Развертывание на Render.com (Бесплатный хостинг)

### Шаг 1: Подготовить репозиторий GitHub

1. Создайте репозиторий на GitHub: https://github.com/new
2. Инициализируйте Git:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/mafia-game.git
git push -u origin main
```

### Шаг 2: Создать сервис на Render.com

1. Перейдите на https://render.com
2. Нажмите **New** → **Web Service**
3. Подключите свой GitHub-репозиторий
4. Настройки:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Environment**: Node
   - **Region**: Выбирайте ближайший

### Шаг 3: Добавить PostgreSQL базу

1. В Render.com: **New** → **PostgreSQL**
2. Укажите:
   - **Name**: mafia-db
   - **Database**: mafia
   - **User**: mafia
3. После создания скопируйте строку подключения `Internal Database URL`

### Шаг 4: Связать БД с приложением

1. Откройте сервис Web Service
2. Перейдите в **Environment**
3. Добавьте переменную:
   - **Key**: `DATABASE_URL`
   - **Value**: (вставьте строку подключения из PostgreSQL)

### Шаг 5: Инициализировать схему БД

После первого деплоя подключитесь к БД и выполните:

```bash
psql <DATABASE_URL> < server/schema.sql
```

Или через Render консоль (Shell в сервисе):
```bash
psql $DATABASE_URL < server/schema.sql
```

## 🎮 Как играть

### Меню
- **Быстрая игра** — присоединиться к случайной комнате
- **Создать комнату** — создать новую игру и пригласить друзей
- **Присоединиться** — вводить код комнаты
- **Локальная игра** — игра на одном устройстве

### Лобби
1. Введите имя или используйте никнейм аккаунта
2. Хост может менять параметры комнаты
3. Все игроки нажимают "Готов"
4. Хост нажимает "Начать игру"

### Игра
**Ночь:**
- Мафия выбирает жертву (скрытый чат)
- Комиссар проверяет игрока
- Доктор лечит
- Остальные ждут

**День:**
- Все обсуждают в чате
- Голосование: каждый выбирает, кого казнить
- Результат: игрок исключается или ничья

**Повторяется** до победы одной из сторон

### Победа
- **Мирные:** уничтожить всю мафию
- **Мафия:** стать равной или больше мирных
- **Маньяк:** остаться последним
- **Шут:** быть казненным голосованием

## 📊 API и события Socket.IO

**Основные события:**

Client → Server:
- `createRoom` — создать комнату
- `joinRoom` — присоединиться
- `playerReady` — готовность
- `nightAction` — ночное действие
- `vote` — голосование
- `chatMessage` — сообщение в чат

Server → Client:
- `state` — обновление состояния игры
- `roleAssigned` — роль назначена
- `playerDied` — игрок погиб
- `gameEnded` — игра закончилась
- `phaseChanged` — фаза изменилась

## 💡 Примеры использования
